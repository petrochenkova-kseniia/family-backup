Privacy Policy

Last updated: November 17, 2026

Family Backup is a personal tool used privately by one family. This policy explains how it uses Google user data.

What data the app accesses

The app requests access only to files in Google Drive that the app itself creates (the drive.file scope). It cannot see or read any other files in the user's Google Drive, Gmail or other Google services.

How the data is used

The app uploads copies of documents and spreadsheets from the user's own computer to a backup folder in the user's own Google Drive, and updates those copies when the files change. That is the only purpose of the app.

Storage and sharing

Files are stored only in the user's own Google Drive. The app does not send data to any other server, does not sell data, does not use it for advertising, and does not transfer it to third parties. The backup folder may be shared by the user with members of their own family using Google Drive's standard sharing.

Access tokens

Access tokens are stored only on the user's own computer. The user can revoke access at any time at myaccount.google.com/permissions.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Коротко по-русски

Программа видит на Google Диске только те файлы, которые создала сама. Она копирует документы с компьютера пользователя на его же Google Диск и больше никуда данные не передаёт. Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions.
